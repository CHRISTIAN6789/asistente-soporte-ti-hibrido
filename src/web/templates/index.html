El incidente es convertido en un vector numérico de características.

¿Qué aporta cada representación?

Representación numérica: permite medir cuantitativamente la similitud entre el incidente actual y un patrón conocido.

Representación simbólica: permite expresar las características del incidente mediante hechos y obtener conclusiones mediante reglas.

Autómata: permite reconocer si una secuencia de acciones corresponde a un proceso válido de atención hasta alcanzar el estado RESUELTO.
