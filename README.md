# 🖥️ Asistente de Soporte TI Híbrido

## Descripción

Asistente de Soporte TI Híbrido es un sistema inteligente desarrollado como proyecto de la asignatura de Inteligencia Artificial.

El propósito del sistema es automatizar la atención y gestión inicial de incidentes tecnológicos mediante técnicas de Inteligencia Artificial, aprendizaje automático y sistemas basados en reglas.

El asistente permite clasificar consultas de soporte, recuperar soluciones desde una base de conocimiento, aplicar reglas de priorización y mantener trazabilidad de las decisiones tomadas durante el proceso.

---

## Objetivo General

Diseñar e implementar un sistema inteligente híbrido capaz de clasificar consultas de soporte técnico, recuperar conocimiento, aplicar reglas de negocio y priorizar incidentes de manera automática y trazable.

---

## Funcionalidades

- Clasificación automática de consultas de soporte.
- Recuperación de conocimiento basado en categorías.
- Aplicación de reglas para toma de decisiones.
- Priorización de incidentes.
- Registro y auditoría de eventos.
- Generación de respuestas sugeridas.
- Trazabilidad de cada decisión del sistema.
